=== English Detailed Description ===

Pixel Color Picker is a cute Chrome extension that lets you pick any color from any web page with a single click.

🎨 Main features
- One-click color picking: click the extension icon → click "Quick Pick" → click anywhere on a page. HEX / RGB / HSL formats supported
- Palette management: create unlimited palettes, rename, delete, export individually
- 12+ preset themes + fully custom themes: Pink, Green, Night, Iris, Oat, Cherry, Game Boy, Cocoa, Mint, Grape, Mist, Cream, plus custom header / button / background / panel colors
- Multi-format export: CSS variables / JSON / Tailwind config / PNG palette images
- Search: quickly find colors in your palettes and history
- Dark mode: follows system automatically
- Bilingual: complete zh-CN / en translations
- Local storage: all data stored in chrome.storage.sync, zero remote calls
