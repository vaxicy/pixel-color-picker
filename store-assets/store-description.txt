=== 中文详细说明 ===

Pixel Color Picker - 像素吸色器

一款轻量、像素风格的网页取色 Chrome 扩展。在任意网页右键即可吸取颜色，自动保存为色卡与历史，并支持多种格式导出与收藏整理。色卡、取色历史和主题设置仅保存在浏览器本地存储中，不会上传任何远程服务器。

主要功能

- 在任意网页右键吸色，自动保存到色卡和历史
- 创建和管理多个色卡，为颜色添加备注
- 搜索、排序和整理色卡中的颜色
- 支持 HEX、RGB、HSL 等常用颜色格式
- 一键复制颜色值
- 导出为 CSS、SCSS、JSON、Tailwind、PNG、CSV、ASE 等格式
- 导入色卡 JSON 文件
- 支持中英文界面
- 像素风主题与自定义颜色

隐私优先

Pixel Color Picker 将色卡、取色历史和设置保存在浏览器扩展存储中。扩展不会出售用户数据，也不会与第三方分享。所有数据仅存于本地浏览器，不向任何远程服务器发送。

适合用于

- 网页设计取色
- UI 设计配色收集
- 前端开发 CSS 变量整理
- 品牌色、主题色和灵感色卡管理
- 日常颜色收藏与导出

=== English Detailed Description ===

Pixel Color Picker

A lightweight, pixel-style color picker for Chrome. Right-click any webpage to grab a color, automatically save it to palettes and history, and export it in multiple formats. Your palettes, history and theme settings are stored only in your browser's local storage and are never uploaded to remote servers.

Main features

- Right-click to pick colors from any webpage and auto-save to palettes and history
- Create and manage multiple palettes
- Add notes, search, sort and organize colors
- Support HEX, RGB, HSL and other common formats
- One-click copy of color values
- Export to CSS, SCSS, JSON, Tailwind, PNG, CSV, ASE and more
- Import palette JSON files
- Chinese and English UI
- Pixel-style themes and custom colors

Privacy first

Pixel Color Picker stores your palettes, color history and settings in your browser's extension storage. The extension does not sell user data or share it with third parties. All data stays locally in your browser and is not sent to any remote server.

Great for

- Picking colors from web pages while designing
- Collecting UI and brand color palettes
- Building CSS variables for front-end projects
- Managing brand, theme and inspiration palettes
- Everyday color bookmarking and exporting
